## Key Insights for Lisa

### Market Gaps to Exploit
1. **Price-Performance Sweet Spot** - Between free tools and premium AccuLynx
2. **Modern AI Integration** - Only JobNimbus has serious AI features
3. **Better Mobile Experience** - Opportunity for mobile-first design
4. **Simpler Onboarding** - Reduce learning curve
5. **Flexible Pricing** - Usage-based or more granular tiers
6. **Multi-Trade Expansion** - Not locked to roofing only

### Must-Have Features (Table Stakes)
1. CRM with pipeline management
2. Estimating with measurement integration
3. Proposal generation
4. Job/project tracking
5. Mobile app
6. QuickBooks integration
7. Photo documentation
8. Payment processing

### Differentiating Features to Consider
1. AI-powered automation
2. Modern, intuitive UX
3. Real-time collaboration
4. Advanced analytics/BI
5. Flexible integrations (API-first)
6. Transparent pricing
7. Self-service onboarding
